// 01 — about

Not just writing code.
Shipping things people use.

I'm a full-stack developer out of Zarqa, Jordan, currently building production web apps at Mibax with Angular on the front and ASP.NET Core underneath. I like the kind of work where you own a feature end to end — schema to API to the pixel the user actually clicks.

I studied IT & Cyber Security at Zarqa University (2024), which means I think about auth, roles, and edge cases a little differently than most frontend-first developers — probably a habit worth keeping.

Outside the day job, I run Merch Dungeon, a print-on-demand business across WooCommerce, Etsy, and Allegro — SEO, fulfillment, and an AI-driven content pipeline, all self-taught and self-run. I'm deep into AI tools and "vibe coding," and genuinely enjoy building side projects faster than I probably should.

When I'm not shipping, I'm competitive about it elsewhere — Rust, League of Legends, Arma. Same instinct, different scoreboard.
